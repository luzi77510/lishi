# 人生有迹 · 历史人物性格映射测试

[在线访问网站](https://luzi77510.github.io/lishi/) · [GitHub 仓库](https://github.com/luzi77510/lishi)

一份可以在浏览器中访问的中文互动网站。以历史档案、手稿和古典出版物为视觉线索，邀请用户回答18个单选问题，从六种行为倾向观察自己的思考与选择，并获得一份历史人物原型画像。

## 本地预览

需要 Node.js 20 或更高版本。项目不依赖 React、npm 包、后端、账号、云数据库或第三方埋点。

```bash
npm test
npm run build
npm run dev
```

如果环境只有 Node.js，可直接运行 `node --test tests/*.test.mjs`、`node scripts/build.mjs` 和 `node scripts/serve.mjs`。

浏览器打开终端显示的网址，默认为 `http://127.0.0.1:5180`。构建后的静态网页位于 `dist/`，也可以直接部署到任何静态网页主机。

## 测试内容

18题分别测量探索创造力 C、目标执行力 A、深度思辨力 R、情感感知力 E、风险决断力 D 与稳定韧性 S。每个维度三道题、满分9分。三种原型的指数和分项权重、匹配度上限、同分时的固定优先级及第四种隐藏结果的四项触发条件均按产品方案计算。

参与者可以返回并修改答案；答题进度保存在当前浏览器的本地存储中，不会上传服务器。完成测试后显示雷达图、详细画像、行动建议与独立触发的隐藏彩蛋。结果支持复制分享和保存 PNG 分享卡片。

## 图片说明

首页与达·芬奇结果页使用达·芬奇历史肖像的公有领域图片，来源为 [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Leonardo_self.jpg)。李清照和沈括结果页使用项目内原创 SVG 文学与天文主题插画；它们是艺术性意象，不是古人真实肖像。

## 趣味测试说明

本测试用于娱乐与自我反思，不是临床心理量表，不用于诊断或重要决策。历史人物映射属于象征性原型，结果匹配度为产品内部的娱乐性指标，不表示人格相似的客观概率，也不是历史人物性格的科学测量。请以自己的感受为准。

## 发布到 GitHub Pages

仓库内的 `.github/workflows/pages.yml` 已配置部署流程。代码推送至 `main` 后，GitHub Actions 会先运行测试和构建，再发布 `dist/`。如这是仓库首次发布，请在 GitHub 仓库的 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**。


近似同分的执行口径：按文档5.4，当最高两项差距小于0.35分时，先比较两者的核心维度总和，再比较各自的最高权重维度；这条规则可能选中原始指数略低的候选。三项指数完全一致时按5.7固定选择达·芬奇型。不存在随机分配结果。
